# 研究大纲 —— 腕部视角增益的条件与机制

> **论文题目（候选）**：《行为克隆中腕部视角的增益条件与机制——LIBERO 跨套件双视角消融研究》
> （备选：《行为克隆中腕部视角的增益条件研究——基于 LIBERO 的双视角消融实验》）
> **一句话主张**：腕部视角补的是"外部视角的失败"，而不是"被挡住的目标"——增益是条件性的、任务相关的，价值集中在"**对准**"环节。
> **数据底盘**：LIBERO 基准（Spatial 10 任务主实验 + Object 4 任务抽检），单卡 6GB；全部数字统一 256 渲染协议、种子固定、断点续跑、可复现。
> **场景学事实（10-12 核查，三重验证）**：Object = **Floor 地面场景**（`LIBERO_Floor_Manipulation`，物体/篮子均在地板）；Spatial/Goal/10/90 = Tabletop 桌面场景——跨套件实为「物体 × 场景类型」复合差异。
> **范围决策（10-12）**：Goal / Long / CALVIN / 真机**均不做**——与本文的机制问题正交（列入未来工作）；外部效度由「主平台全量 + 跨套件抽检」承担。

- **1.2 ✅** 统一评测协议：256 渲染锁定、降采样档（128/256）一致、运行间波动 ±4pp
- **1.3 ✅** 极端值复核：task9 逐局一致 / task7 ±2 局 / task6 @128 ≈ @256
- **1.4 ✅ Object 跨套件抽检**（字母汤/烧烤酱/黄油/橙汁 × 单双 = 8 单元）
  - 目的：结论的**外部效度**——"是不是 Spatial 特有的？"
  - 检验点（更新）：① 增益仍为正 ✅（+66 / +32 / +78 / **+88pp**）；② 失败画像（**两项测量口径修正**：g1 判定器失效 + 初始弹出伪影，见论文 5.6/7.5）：单相机失败集中于「抓取-运输链条」（合计占 75%~100%），腕部视角基本清零、残余回落为抓取/放置混合型；③ 瞄准指标在 Object 弃用（判定器失效）

## 第二部分　增益的条件：什么时候有增益（"什么时候"）
- **2.1 ⭐ ✅** 任务级规律：增益集中于单相机失败的任务（Spatial 10 任务 r=−0.88 → **跨两套件 14 任务 r=−0.94**）
- **2.2 ⭐ ✅** 配对分解：修复 135 / 破坏 54（净 +81 对）；负增益任务 = **破坏主导**（task7 修 2 坏 19）
- **2.3 ✅** 初始位姿级分析（n=700 完成）：把条件从 14 个任务点升级到 700 个开局点。**结论（负结果）**：开局级几何无预测力（套件内 r≈0：Spatial +0.003 / Object +0.161；任务内近/远半二分 12/14 差异<20pp）；跨套件混合的 r=+0.245 为 **Simpson 型混杂**（远距样本均来自 Floor 场景）；任务级 r(任务 d_goal, 单相机)=−0.35、r(,救援)=+0.44，**显著弱于**单相机基线预测力（−0.94）→ **几何距离不是腕部视角增益的核心条件变量**（真变量是「策略的抓取-搬运链条是否完整」）。附带场景学发现见「数据底盘」。
- **2.4 📋** 负增益解剖：task7/8 被破坏回合的共性（崩在哪个阶段、碗在什么位置）（A5）

## 第三部分　增益的机制：为什么有增益（"为什么"）—— 即"四层机制链"
- **3.1 ✅ 观测层**（四层①）：遮挡补偿假说 → **否证**（增益 vs 遮挡 r=−0.33 ~ −0.45，方向相反）
- **3.2 ✅ 表征层**（四层②）：空间信息假说 → **否证**（分阶段解码四段均无优势；**表征-控制分离**）
- **3.3 ⭐ ✅ 行为层**（四层④）：**抓取对准假说 → 强支持**（5 条交叉证据：瞄准 6.5→5.5cm、r=−0.72、抓取失败 −74%、灾难脱靶 −66%、剂量-反应 >8cm→8%）
- **3.4 ✅ 因果层**（四层③）：阶段干预（**冻结+重放双对照**）→ 7/10 为伪影；腕部通道深度嵌入控制回路；2 格残留
- **3.5 📋** 放置残留复核：task7/8 放置阶段（时序对齐版重放，B10）
- **3.6 📋** 干扰物机制：task7/8 腕部画面干扰占比 vs 破坏率（C13）
