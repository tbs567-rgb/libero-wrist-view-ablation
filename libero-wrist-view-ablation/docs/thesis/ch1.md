# 第 1 章 绪论

> 状态：B4 批次初稿（2026-10-13）。文献 [1]-[4] 已联网核实；其余经典文献条目引用前需逐条复核（见文末清单标注）。

## 1.1 研究背景与意义

### 1.1.1 从"能不能做"到"该怎么看"：机器人操作学习的观测配置问题

视觉-语言-动作（Vision-Language-Action, VLA）大模型近两年把通用机器人操作推到了前所未有的高度：RT-2、PaLM-E、OpenVLA、π0 等工作展示了从互联网级预训练到机器人控制的迁移能力[ref: RT-2 2023; PaLM-E 2023; OpenVLA 2024; π0 2024]，而 LIBERO[ref: Liu et al., NeurIPS 2023]等标准化基准的出现，使不同方法可以在同一组任务、同一批初始态上受控比较。在 LIBERO-Spatial 这样的标准套件上，最先进方法的成功率已经达到 97% 以上——例如 2025 年的 VLA-Adapter[ref: Wang et al., arXiv:2509.09372]以约 0.5B 参数的轻量骨干报告了 97.8%（Pro 版 99.6%）。

然而，在追逐"更高成功率"的竞赛中，有一个**每个部署者都必须回答、却在论文里几乎从不被讨论的问题**被当成了默认前提：**机器人应该装哪些相机？** 具体到 LIBERO 这类标准评测，几乎所有头部方法都同时使用第三人称相机与腕部相机两个视觉流——包括上述轻量级的 VLA-Adapter（其开源训练配置中 `num_images_in_input=2`，即第三人称 + 腕部双图输入）。多视角配置已经成为社区事实上的默认先验：**它被普遍使用，却很少被系统性地追问"值多少分、什么时候值、为什么值"。**

这不是一个小问题。相机不是免费的超参数：每一路相机都意味着额外的标定、带宽、延迟、故障点与更长的输入序列；对算力受限的部署场景（教育、中小实验室、嵌入式平台），这直接决定方案可行性。更根本地，从科学角度讲，**一个被所有方法默认采用、却从未被消融的组件，其贡献是未知的**——它可能贡献巨大，也可能只是"大家都这么用"的惯性。回答这个问题，既能为工程部署提供决策依据，也是对当前评测惯例的一次方法学补课。

### 1.1.2 低资源设定：把问题缩小到可控的尺度

系统消融需要控制变量：数据、网络、超参、评测协议全部相同，只变观测配置。要做到这一点，最理想的载体不是参数以十亿计、训练以 GPU 集群计的大模型，而是一个**在消费级显卡上数小时内可完成训练-评测全流程的小模型**——它让"每个实验点都换种子重跑"成为可负担的纪律，而不是奢望。

本文因此采用 6GB 单卡可训的行为克隆（Behavior Cloning, BC）设定：以 ResNet-18 为骨干、帧堆叠 + 通道拼接为融合方式、LIBERO 官方演示为数据。该设定不追求与 VLA 比拼绝对分数（本文的 BC 基线为 67.6%~84.6%，VLA-Adapter 为 97.8%），而是把研究问题精确化：**在其余一切相同的前提下，腕部视角这一观测维度本身，对策略性能的贡献是多大、由什么决定、通过什么机制实现。**低资源在这里不是妥协，而是方法学选择——它换来的是 1400 局以上的受控评测、跨种子的稳健性检验，以及逐局的行为级测量。

### 1.1.3 研究意义

- **科学意义**：为"多视觉配置"这一被默认的先验提供首批（据我们所知）跨套件、带机制分析、带种子层面稳健性检验的系统性消融证据，并给出可预测的定量规律（r = −0.94）；
- **方法学意义**：发现并量化单侧模态消融（只做"冻结"）的系统性偏差，提出"冻结 + 重放"双对照协议；配套渲染协议锁定、运行波动量化等六条测量规范，可直接被后续工作复用；
- **工程意义**："要不要加腕部相机"从经验判断变为可由单相机基线预测的决策：本文的规律表明，该决策可以在不训练双相机模型的情况下预先估计。

## 1.2 国内外研究现状

### 1.2.1 视觉-语言-动作大模型与多视角的默认配置

自 RT-2[ref: Brohan et al., 2023]将网络级视觉-语言预训练迁移到机器人控制以来，VLA 路线迅速成为操作学习的主流：PaLM-E[ref: 2023]扩展了具身推理，OpenVLA[ref: Kim et al., 2024]以 7B 开源模型确立开放基线，π0[ref: Black et al., 2024]与 Octo[ref: 2024]推动了通用策略与跨具身数据训练，Open X-Embodiment[ref: 2023]则提供了跨机构的数据底座。面向轻量化，VLA-Adapter[ref: Wang et al., 2025]证明 0.5B 骨干 + Bridge Attention 即可在 LIBERO 上达到 97.8%，并将训练压缩到单卡 8 小时。

这些工作的共同点在于：**观测配置不是研究对象**。上述模型无一例外地同时使用多个相机流（第三人称 + 腕部是标准配置），但没有一篇报告"去掉腕部相机会损失多少"——多视角的有效性被隐含在整体性能里，从未被单独度量。换言之，社区在"模型怎么更大"上投入了大量消融，而在"观测应该怎么布"上几乎没有任何受控证据。

### 1.2.2 眼在手上视觉与操作学习

腕部相机（eye-in-hand）本身有深厚的实践传统。早期大规模验证来自 Levine 等[ref: Levine et al., 2018]与 QT-Opt[ref: Kalashnikov et al., 2018]：数台机械臂数月级自监督抓取，证明了腕部视角对**抓取**这一特定环节的价值。视觉伺服领域的经典综述[ref: Chaumette & Hutchinson, 2006]则从控制理论角度系统化 eye-in-hand 的定位优势。这些工作确立了"腕部相机有用"的直觉，但它们（i）以强化学习或大规模自监督为范式，与今天的演示学习（模仿学习/BC）设定不同；（ii）报告的是聚合收益，未刻画"何时有用、何时无用"的条件结构；（iii）不提供机制层面的分解。

与本文最直接相关的是 Look Closer[ref: Jangir et al., IEEE RA-L 2022]：在 xArm7 平台上以 RL（SAC）训练，提出 cross-view attention Transformer 融合第三人称与腕部视角，真机 Hammer 任务从单视角 13% 提升到 75%（多视角基线 38%），并迁移到无标定真机。**它是"融合腕部视角能有效提升精度操作"这一命题最有力的方法学证据，也是本文的正面对标**。但其定位是方法论文：贡献在于融合架构与真机迁移，未涉及条件结构（哪些任务受益）、未报告任何负结果、也没有机制归因。

### 1.2.3 相机配置的比较研究与主动视觉

把"相机该放哪"作为研究对象的近期工作很少。AV-ALOHA[ref: Chuang et al., arXiv 2024]在 ALOHA 双臂平台上加入一条专责"主动视觉"的 7-DoF 相机臂，由模仿学习同时训练操作策略与视点策略，发现主动视觉在遮挡/高精度任务上大幅受益（穿针 30%→52%），但**对简单任务，额外自由度偶有负面作用**——这与本文"观测配置的收益是任务依赖的"结论方向一致。该工作研究的是"让相机动起来"，本文研究的是"静态双相机的价值条件与机制"，两者互补。此外，LIBERO 原论文[ref: Liu et al., 2023]本身在架构与算法维度做了系统消融（视觉编码器、终身学习算法等），其消融精神是本文在"观测配置"维度上的直接先例——本文相当于把 LIBERO 式的系统消融补在了它自己没有覆盖的维度上。

### 1.2.4 实验方法学：深度学习实证研究的先例

本文的第三条贡献线（测量规范）在深度学习实证研究中有清晰的先例传统：Recht 等证明 ImageNet 分类器在分布微移下的排序不稳定[ref: Recht et al., 2019]；Engstrom 等系统记录实现细节对深度强化学习结论的颠覆性影响[ref: Engstrom et al., 2019]；Musgrave 等对度量学习领域"SOTA 竞赛"的复现审计[ref: Musgrave et al., 2020]；Agarwal 等为深度 RL 给出了统计报告规范（少样本下的置信区间与性能曲线）[ref: Agarwal et al., 2021, NeurIPS]。这些工作的共同信条是：**结论的可信度取决于测量协议，而非仅仅取决于模型**。本文把这一信条引入机器人多模态消融：渲染协议作为第一类混淆变量、评测运行波动 ±2 局级的量化、"冻结 + 重放"双对照——均为该传统在具体问题上的落地。

### 1.2.5 研究缺口小结

综上，现有研究存在三个缺口：**（i）无受控消融**——多视角配置被 VLA 与 BC 方法普遍默认采用，但"单 vs 双"在同一数据/模型/协议下的严格对照缺失；**（ii）无条件规律**——没有工作给出"给定 X 即可预测收益"的定量关系，也没有工作报告并解释负增益；**（iii）无机制分解**——收益被归因于"更多信息"，但遮挡补偿、空间编码、行为对准等具体通路未被分离检验。本文针对这三个缺口展开。

## 1.3 研究问题

本文提出两个可证伪的研究问题：

**RQ1（条件）**：腕部视角的性能增益在哪些任务上出现？它能否由任务的可观测属性（单相机基线、开局几何、遮挡程度）提前预测？

对应可证伪命题：若增益与单相机基线无关，则"条件规律"不成立；若跨套件（不同物体家族、不同场景类型）增益方向不一致，则规律不具泛化性。

**RQ2（机制）**：增益通过什么机制实现？具体地，三个候选通路的相对贡献如何——（a）遮挡补偿（看到被挡的目标）、（b）空间信息补充（特征含更精确的位置）、（c）行为对准（抓取瞬间的对准质量提升）？

对应可证伪命题：若（a）成立，增益应与遮挡量正相关；若（b）成立，双相机特征的空间解码精度应显著更高且与增益相关；若（c）成立，抓取类失败的修复应构成净增益主体，且瞄准误差的改善应与增益共变。

## 1.4 本文创新点

本文定位为实证与机制研究，不提出新的融合架构。创新点分属三类——**规律发现、机制发现、实验方法创新**：分别回答"何时有用""为何有用""怎样测才不会测错"；第三条本身即为可迁移的新方法。

**创新点一（规律发现）：腕部视角的增益可由单相机基线定量预测，且该规律在多种子检验下保持稳健。** 在 LIBERO 双套件 14 个任务、每任务 50 局官方协议评测上，增益与单相机基线强度呈强负相关——r(增益, 单相机基线) = −0.94，增益区间 +88 ~ −28pp。该规律对单种子不确定性稳健：对唯一的多种子检验点（炉灶 t7，8 单元）而言，其单种子口径的负增益（−28pp）经检验主要由单相机基线的种子方差贡献（基线在 2%~94% 间振荡），多种子均值口径下该任务增益为 +35.3pp，替换后规律相关系数仍为 −0.939。同时双相机的种子方差显著小于单相机（0/16.0 vs 8.3/46.1 pp）——多出的信息不仅提升均值，也压缩方差。与既有工作的区别：既有多视角工作只报告"融合更好"，未给出可预测的定量规律，也未对负结果做种子层面的检验。

**创新点二（机制发现）：增益机制定位于"抓取对准 / 接触阶段"，并否证三类直觉解释。** 遮挡补偿被否定（增益与遮挡度量反向相关，r = −0.44）；空间信息可解码性未获支持（线性探针 ΔR² 与增益无关，存在"表征-控制分离"）；开局几何被排除（n=700 开局级分析，套件内相关≈0，跨套件表面相关为 Simpson 型混杂）。正面定位：腕部视角主要消灭抓取失败（−74%），闭爪瞄准误差显著缩小（r(增益, Δ瞄准) = −0.72），脱靶事件下降 66%，且跨套件失败画像（地面场景 Object 的"抓取-运输链条断裂"占 75%~100%）被清零。区别：把"更多信息所以更好"的直觉变为可证伪的机制定位。

**创新点三（实验方法创新）：提出模态消融的"冻结 + 重放"双对照协议，并配套测量规范。** 仅"冻结"模态会把静止画面变成分布外输入、系统性夸大信息依赖；加入"重放真实画面"对照后，10 个干预格中 8 个被判定为伪影、1 个部分依赖、1 个稳健真依赖。配套五条测量规范：渲染协议锁定（第一类混淆变量）、评测运行波动 ±2 局级的量化与处置、探针判定器逐任务族校准、开环误差对照、复现纪律。区别：现有多模态消融普遍只做单侧移除/冻结；本文指出其系统性偏差并给出可复用的替代协议。

> **关于创新点类型的说明**：本文不提出新的融合架构，创新点属于"规律发现 + 机制发现 + 实验方法"三类。在以方法为主流的会议文化中，系统性实证与实验方法学贡献具有独立价值；且创新点三本身即为一种新方法——它改变的是"如何测量"，而非"如何建模"。

## 1.5 论文组织结构

第 2 章介绍实验平台与方法（LIBERO 双套件、行为克隆模型、官方评测协议、机制探针与六条测量规范）；第 3 章报告系统性测量结果（增益谱、跨套件复现、条件规律、开局级分析与定性证据），回答 RQ1；第 4 章报告机制分析（假说排除、抓取对准定位、失败画像、因果干预），回答 RQ2；第 5 章给出稳健性分析（多种子复现、运行波动、渲染敏感性、测量口径修正记录）；第 6 章讨论与 Look Closer 等工作的对照定位、对部署实践的建议及局限性；第 7 章总结全文并展望。附录 A 记录六类失效技巧的负结果，附录 B 给出超参数与复现命令，附录 C 为失败案例视频集说明。
