# 第 3 章 双视角增益的系统性测量

> 状态：B2 批次初稿（2026-10-13）。本章回答研究问题 RQ1（增益何时出现、能否预测）。全部数字的口径与复现命令见《数据溯源手册》；负增益的多种子检验见 3.3 与 5.2 节。

## 3.1 主结果：14 个任务的增益谱

### 3.1.1 总体结果

在 LIBERO-Spatial 的 10 个任务与 LIBERO-Object 抽检的 4 个任务上，本文分别训练并评测了单相机（仅第三人称）与双相机（第三人称 + 腕部）两个行为克隆模型。**表 3-1** 给出全部 14 个任务的逐项成绩（官方协议：每任务 50 个初始态、256 渲染、成功由环境判定）。

**表 3-1　14 任务"单 → 双"成绩总表（每格 50 局）**

| 套件 | 任务 | 单相机 | 双相机 | 增益 Δ |
|---|---|---|---|---|
| Spatial | 0 盘盅之间 | 66% | 70% | +4* |
| Spatial | 1 烤盅旁 | 76% | 92% | +16 |
| Spatial | 2 桌中央 | 44% | **100%** | **+56** |
| Spatial | 3 盒上 | 58% | 96% | +38 |
| Spatial | 4 抽屉顶 | 100% | 96% | −4* |
| Spatial | 5 烤盅顶 | 82% | 92% | +10 |
| Spatial | 6 盒旁 | 34% | 76% | **+42** |
| Spatial | 7 炉灶上 | **94%** | 66% | **−28**† |
| Spatial | 8 盘旁 | 78% | 64% | **−14** |
| Spatial | 9 木柜上 | 44% | **94%** | **+50** |
| Object | 0 汤罐 | 22% | 88% | **+66** |
| Object | 3 酱瓶 | 60% | 92% | +32 |
| Object | 6 黄油 | 12% | 90% | **+78** |
| Object | 9 橙汁 | **6%** | **94%** | **+88** |
| **Spatial 平均（10 任务）** | | **67.6%** | **84.6%** | **+17.0pp** |
| **Object 平均（抽检 4 任务）** | | **25.0%** | **91.0%** | **+66.0pp** |

> \* |Δ| ≤ 4pp（约 2 局）处于实测运行波动带内（见 5.3 节），不做方向性解读；
> † 该负增益经多种子检验主要由单相机基线的种子方差贡献（见 3.3 节与 5.2 节）。

三个总体观察：

1. **双相机平均大幅领先**：Spatial 上 67.6% → 84.6%（+17.0pp），较 LIBERO 官方 BC-RNN 基线（60.9%）高出约 24pp；Object 上 25.0% → 91.0%（+66.0pp）。
2. **增益高度任务依赖**：14 个任务的增益从 +88pp 到 −28pp 横跨整个区间（10 正 / 2 波动带 / 2 负，按 3.3 节的符号判据）。
3. **越差越救**：增益最大的任务恰是单相机基线最差的任务——桌中央（44%→100%，+56pp）、盒旁（34%→76%，+42pp）、木柜上（44%→94%，+50pp），以及 Object 上全线崩盘的四个任务（6%~22% → 88%~94%）。

增益谱的可视化见图 3-1（`figs/fig1_gain_spectrum.png`）：每个任务一行，按单相机基线升序排列，可直观看到"基线越低、线段越长（增益越大）"的整体模式。

### 3.1.2 多种子抽检：均值、方差与负增益的性质

单次训练的结果受随机种子影响。为量化这一不确定性，本文对两个代表性任务——t2（旗舰正增益案例）与 t7（旗舰负增益案例）——各补训 2 个种子（单/双两配置，共 8 个训练-评测单元，每个单元 600 epoch 训练 + 50 局评测）。

**表 3-2　多种子抽检结果（每格 = 3 个种子的成功率）**

| 配置 | seed7 | seed1 | seed2 | 均值 ± 标准差 |
|---|---|---|---|---|
| t2 单相机 | 44% | 56% | 40% | 46.7 ± 8.3 |
| t2 双相机 | 100% | 100% | 100% | **100.0 ± 0.0** |
| t7 单相机 | 94% | **2%** | 44% | 46.7 ± **46.1** |
| t7 双相机 | 66% | 82% | 98% | 82.0 ± 16.0 |

三个发现（详见 5.2 节）：

1. **多种子均值口径下，两个抽检任务的增益均大幅为正**：t2 为 +53.3pp、t7 为 +35.3pp。
2. **双相机的种子方差显著小于单相机**（0 与 16.0 vs 8.3 与 46.1 pp）：多出的视觉信息不仅提升均值，也把策略推进了更宽的成功盆地。
3. **单种子口径下的"负增益"需要谨慎解读**：t7 的单相机基线在种子间于 2%~94% 之间剧烈振荡（其中 2% 的种子为欠收敛训练，其训练集 MSE 为收敛种子的 3 倍），seed7 的 94% 属于幸运种子。因此 t7 的 −28pp 负增益**主要由单相机基线的种子方差贡献，而非"腕部视角有害"**——将 t7 替换为其多种子均值后，3.3 节的条件规律相关系数几乎不变（r = −0.939）。

这一抽检同时构成对本文自身结论的稳健性检验：第 5 章将把它与评测运行波动（±2 局级）合并为完整的"结论可信度"分析。

## 3.2 Object 跨套件复现

Spatial 的结论若只在同一套任务上成立，说服力有限。Object 抽检（4/10 任务）在三个维度上构成更严格的检验：物体家族完全不同（碗 → 罐头/酱瓶/黄油/橙汁）、任务目标不同（放盘 → 入篮）、**场景类型不同**（桌面 → 地面，见 2.1 节场景学核查）。

结果（表 3-1 下半部分）显示，增益的方向与量级完整复现：四个任务全部大幅正增益（+32 ~ +88pp），套件平均 25.0% → 91.0%（+66.0pp）——**增益幅度远大于 Spatial**，原因正是 Object 的单相机基线全线更低（6%~60%）。套件内部再次单调呈现"越差越救"：单相机 6% → +88pp、12% → +78pp、22% → +66pp、60% → +32pp。

极端案例是橙汁（t9）：单相机仅 6%，为全研究最低基线；双相机 94%，+88pp 为全场最大增益。第 4 章的失败画像将说明，其 47 个失败局中 46 局属于"从未接近目标"的极端失败型——腕部视角甚至能救活"不敢动手"的策略。

**图 3-2　Object 失败画像**（`figs/fig4_object_failures.png`，各类失败局数的单/双对照）

需要说明的是，Object 为 4/10 任务的抽检，本文在所有结论表述中均标注"抽检"属性，不做整套件外推。

## 3.3 条件规律：增益由单相机基线预测

### 3.3.1 规律表述

将 14 个任务的（单相机基线，增益）作为数据点，两者呈强负相关：**r(增益, 单相机基线) = −0.94**（图 3-3，`figs/fig2_baseline_vs_gain.png`）。用语言表述：**给定一个任务的单相机成功率，就可以定量预判加入腕部视角的收益**——基线越差，救得越狠；基线接近饱和时，额外视角带来的收益趋近于零甚至为负。

**图 3-3　基线-增益散点与线性拟合**（r = −0.944）

### 3.3.2 两点统计学讨论

**（1）性能上界效应。** 该负相关部分来自统计上的"天花板约束"：基线接近 100% 的任务没有提升空间。但天花板效应无法解释全部现象——同为高分任务，t4（基线 100%）的 Δ 为 −4pp（波动带内），而 t7（基线 94%）的 Δ 为 −28pp，远超天花板效应的预期幅度；且低基线任务的增益差异同样巨大（44% 的 t2 拿到 +56pp，44% 的 t9 拿到 +50pp，而 60% 的 t3 只有 +32pp）。规律的主体是真实的模型行为差异，而非纯统计 artifact。

**（2）多种子稳健性。** 14 个点中唯一经过多种子检验的"负增益点"t7，在种子均值口径下回归趋势线（基线 46.7、增益 +35.3；替换后 r = −0.939）。这意味着：t7 在单种子口径下的负增益，恰恰是**条件规律自身**所预言的"基线不确定性"的一个实例——单相机策略在高分任务上的种子方差，会被单次评测误读为"腕部视角有害"。本文因此建议：文献中报告的负结果（含本文 t8 的 −14pp，未做多种子检验）都应在多种子复核后再做机制归因。

### 3.3.3 与既有发现的对照

这一"任务依赖、越差越救"的模式与 Active Vision 方向的独立结论[ref: Active Vision Might Be All You Need, 2024]相互印证——该工作在 ALOHA 平台上对比 8 种相机配置，同样发现"没有一种配置全赢、腕部相机有时关键有时有害"。本文的差异在于给出了**可预测的定量规律**（r = −0.94）与**负增益的种子层面解释**。

## 3.4 开局级条件分析：几何距离不是核心变量

任务级的条件规律（3.3 节）把"何时有用"归因于单相机基线强度，但基线强度本身由什么决定？一个直觉解释是**开局几何**：物体离容器越远、越难够到，单相机越容易失败，腕部视角越有用。

为检验这一假说，本文对全部 14 个任务 × 50 个官方初始态（共 **700 个开局**）提取初始位姿特征（物体/容器的平面坐标、物体-容器距离 d_goal、物体-夹爪初始距离），并与机制探针的逐局成败（单/双同初始态配对）联合分析。该分析只需恢复仿真状态、不需要运行模型，是零推理成本的。

三层结果（图 3-4，`figs/fig3_init_pose.png`）均**否定**该假说：

1. **开局级**：d_goal 与成败的相关极弱——套件内按"救援率"（双成且单败）计，Spatial r = +0.003、Object r = +0.161；任务内按各任务 d_goal 中位数二分，14 个任务中 12 个的"近半 vs 远半"成功率差异小于 20pp（平均 8.9pp，方向对半）。
2. **混杂识别**：跨全部 700 局的表面相关（救援率口径 r = +0.245）为**套件混合效应**（Simpson 型混杂）——大距离样本几乎全部来自地面场景的 Object 任务，而该套件的单相机基线本身更低；套件内分别计算后相关归零。
3. **任务级**：任务平均 d_goal 与单相机成功率的 r = −0.35（与救援率 r = +0.44），远弱于"单相机基线"的预测力（−0.94）。

**图 3-4　开局级证据三联**（任务级相关 / Simpson 分解 / 任务内近-远半差异）

**结论（有价值的负结果）**：腕部视角的"救与不救"不由开局几何决定；"距离/可达性"的直觉解释被数据排除。结合第 4 章，真正的条件变量是**策略在单相机下能否建立完整的抓取-搬运链条**。需要说明的功效限制：官方初始态的任务内距离跨度仅 3~7cm，开局级效应的检验功效有限；大范围距离变化下的行为需要专门实验（列入未来工作）。

## 3.6 本章小结

本章在 14 个任务 × 2 配置 × 50 开局的规模上完成了系统性测量：双相机平均增益 +17.0pp（Spatial）与 +66.0pp（Object），增益谱横跨 +88 ~ −28pp；增益由单相机基线定量预测（r = −0.94），该规律在多种子检验下稳健，且把单种子口径下的"负增益"解释为基线种子方差；开局级分析（n=700）排除了"几何距离"这一直觉解释。这些测量确立了一个清晰的现象层：**腕部视角的价值高度任务依赖，且可由单相机基线预测**。其机制原因（为什么是抓取对准、为什么有方差压缩效应）留待第 4 章分解。
